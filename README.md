# Infosys-prep-journey

A structured day-by-day preparation repository for Infosys training, containing Java, SQL, OOP, DBMS, coding practice, revision notes, and interview preparation. This repo documents my learning progress, practice work, mistakes, and topic-wise revision as I strengthen core computer science fundamentals before joining Infosys.
